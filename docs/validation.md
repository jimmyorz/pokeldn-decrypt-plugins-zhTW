## 檢查結果

- 在 `POKELDN_PREVIEW=1` 下執行本次基準的 `scripts/check_language_pack.py`：主字串缺漏 0、多餘鍵值 0、格式變數名稱差異 0；未知工具說明鍵值 0。
- 全部 1,766 個主字串均通過執行期格式化。另比較變數名稱、數量、轉換方式與格式規格，唯一允許的既有例外仍是 `gts.open_until_offer_answered_3c9d1f` 的 `{value2:.0}`；已檢查 0、1、2、100 筆時不顯示多餘的 s。
- 已確認 29 筆新增主字串與確認稿相同，7 個舊鍵已移除，其餘舊主字串保持原樣；圖鑑比例使用半形斜線，實際格式化為「銀行已收集 20/100 種寶可夢，其中 3 種有異色個體」。
- 驗證 LAN 開房與加入的名稱、忽略密碼的操作說明、不需開發板的設定，以及一般交換留空時的隨機個體說明；模擬神秘禮物欄位仍不啟用隨機交換。
- 驗證 5 筆新增 help、4 筆改寫 help 與新工具的 17 筆 messages 回退翻譯可正確套用。
- 使用既有 PKHeX 名稱快照檢查 2,279 筆合併名稱對照，並抽查禮物動態描述、異色倒數及頭目限制訊息；未啟動實際 PKHeX 服務。
- 使用本次基準的上游封裝工具打包，保留 `exclude = ["README.md"]`。包內只有 `LICENSE`、`plugin.toml` 與五個翻譯 TOML，共 7 個檔案，逐一與來源比對一致；20 筆側邊欄翻譯均已包含。
- 通過隔離資料目錄安裝、儲存語言設定與新程序載入，並確認安裝後可讀取新增翻譯及側邊欄翻譯，且沒有 README.md。
- 套件大小為 129,791 位元組；版本、Plugins API、來源清單、英文 Git blob SHA、各檔案 SHA-256 與封裝內容一致。既有 1.0.0 至 1.0.6 套件保持原始位元組。

## 已知限制

- 含預覽功能在內共有 2,368 個工具選項說明，help 直接翻譯 581 個；其餘 1,787 個未另設工具專用對照，部分可使用 messages 回退，其餘顯示英文。
- 銀行能力表的 HP、Atk、Def、SpA、SpD、Spe 直接顯示固定文字，未呼叫翻譯函式；現有對照也不會套用。中文欄位標題採短譯，但欄位寬度仍需完整 GUI 確認。
- PKSM 匯入摘要與版本不支援、檔案不完整等錯誤直接顯示原始文字；新增 messages 或 templates 目前不會生效。
- Showdown 匯出配置由上游產生英文，保留以供匯入使用。隨機交換紀錄的標題可以翻譯，但後面的寶可夢摘要仍取自原始資料。
- GTS 的部分交換條件與拒絕原因未經語言包替換。銀行批次刪除提示中的名稱與名稱排序仍使用原始資料。
- 「讀取我的資料」的遊戲名稱與日期、未接入翻譯流程的底層輸出、開發板診斷、原始錯誤，以及新增的 `[lan]`、`[sw]` 紀錄仍有英文。
- 銀行的 `bank.file_unreadable_0fd8f4` 仍可能顯示上游傳入的英文複數字尾 s，本次未調整。
- 本次未在完整 GUI、真實 Switch 或開發板上實測，也未驗證實際 PKHeX 服務、PKSM 檔案匯入或 LAN 交換。

後續更新方式見 [maintenance.md](maintenance.md)。驗證文件不隨 `.pokeplugin` 發布。
